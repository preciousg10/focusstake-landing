> "Stake Your Focus. Earn Your Rewards." The marketing and pre-launch landing page for FocusStake.

A single-page static site that introduces FocusStake and its AI study features (Snap Solve and Quiz Generation) and collects early sign-ups ahead of the March 1, 2026 launch. Built as a team project; this repo is a public showcase.

## Table of Contents

- [Features](#features)
- [Running Locally](#running-locally)
- [Tech Stack](#tech-stack)

## Features

- Hero, feature highlights, how-it-works, pricing, and testimonial sections.
- Launch countdown and email sign-up call to action.
- Responsive, single-file static build with no dependencies.

## Running Locally

Open `index.html` directly in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Tech Stack

HTML, CSS, and vanilla JavaScript. No build step required.
